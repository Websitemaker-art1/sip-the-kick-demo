# SIP THE KICK — Website Demo v2

A mobile-first static cafe website concept.

## Included
- Full structured menu from the supplied menu screenshots
- Menu search
- Category filters
- Three supplied customer reviews
- Demo phone/WhatsApp number: 0000000000
- Editable contact/location messaging
- Responsive layout

## Deploy
Upload `index.html` and the `assets` folder to any static host such as GitHub Pages, Netlify, Cloudflare Pages, or similar.

## Important
The menu and reviews are based on information supplied for this demo. Confirm prices, address, opening hours, phone number, photos, and other business details with the cafe owner before publishing a production website.
